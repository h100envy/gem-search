# Gem Search / Economy Autolaunch

Локальный дашборд: проекты и нарративы → четыре проверки → собственная концепция → постоянная очередь → Solana / Pump.fun.

## Запуск

Python 3.11+, Node.js 22+. Зависимости Python не требуются; Solana SDK закреплён в package-lock.json.

```sh
cd './gem-search'
npm ci --ignore-scripts
python3 app.py --autopilot
```

Открой http://127.0.0.1:8787. Сейчас `.env` содержит `LAUNCH_MODE=dry_run`: поиск работает, очередь проходит локальную репетицию. Подписи, загрузки метаданных и отправки транзакций отсутствуют. Это не on-chain simulation.

**Подключение реального автозапуска: [SETUP.md](../SETUP.md).** Уже создан отдельный локальный кошелёк, он не пополнен. Нужен также Pinata JWT. Конфигурация загружается из `.env` без исполнения shell; окружение имеет приоритет.

## Лимиты и исполнение

- **0,025 SOL на попытку**, включая комиссии; **5 попыток за скользящие 24 часа**. Максимальное резервирование: **0,125 SOL / 24 часа**, до **3,75 SOL за 30 дней**. Это потолок, не фактическая цена и не обязательная квота.
- Казначейство подписывает только самостоятельно построенное пополнение отдельного creator wallet: 25 000 000 lamports минус комиссия пополнения. Транзакцию провайдера подписывает только изолированный кошелёк. Дальнейшие расходы ограничены выделенным балансом.
- После успешного создания остаток возвращается в treasury, если его хватает на комиссию возврата. После ошибки средства могут остаться в отдельном кошельке; ключ сохраняется.
- Dev buy = 0. Валидатор допускает только ComputeBudget и один Pump create/create_v2 с точными mint, creator и метаданными. Покупки, продажи и дополнительные режимы запрещены. Таблицы адресов проверяются через finalized RPC.
- Неудачные попытки также учитываются. Подписанная транзакция сохраняется до отправки. При неизвестном результате новые выделения SOL блокируются; вместо повторной отправки сверяется прежняя подпись.
- SQLite хранит резервы между перезапусками; файловая блокировка предотвращает одновременное исполнение несколькими процессами. Пауза проверяется перед отправкой и сохраняется; уже отправленную транзакцию отменить нельзя.
- Один проект запускается один раз. Нарратив - не чаще раза в 7 дней и на новом наборе свидетельств. Демо исключено. Нет подходящих кандидатов - нет запусков.

Ограничение списаний предполагает сохранность локальных файлов и отсутствие другого ПО, использующего тот же treasury. API-подписки не входят в лимит SOL. Не удаляй SQLite и ключи отдельных кошельков: вместе они обеспечивают восстановление и защиту от дублей.

## Экономия и источники

**Hacker News:** официальный бесплатный API, до 30 top stories раз в 30 минут, свежесть 24 часа. Темы: agents, robotics, privacy, devtools, science. Shortlist требует ≥3 публикаций, ≥3 доменов, ≥3 авторов, ≥100 points и ≥20 комментариев. Это признаки внимания, не доказательство органического интереса или качества проекта. HN не заменяет полную ленту X; points не означают уникальных пользователей.

**Проверки:** локальные правила вместо платных LLM. Названия и геометрические PNG-значки генерируются локально. DOTS - четыре правила с объяснениями, а не четыре языковые модели. Shortlist не подтверждает безопасность, права на бренд или доходность. Автоматические токены используют собственные названия и описание отсутствия аффилиации.

**Pinata:** публичные PNG и JSON. На проверенной странице free tier: 1 GB, 500 файлов, 10K запросов. По два файла на токен - около 250 запусков в пределах лимита файлов; неудачные попытки также могут оставлять файлы. Приложение не подключает платный тариф. Документация: https://pinata.cloud/pricing и https://docs.pinata.cloud/api-reference/endpoint/upload-a-file.

**RPC:** публичный Solana endpoint по умолчанию; возможны ограничения частоты. Собственный endpoint задаётся через SOLANA_RPC_URL.

**X:** опциональный официальный recent search, до 100 постов за запрос, первая внешняя ссылка каждого поста. Даже с ключом X выключен, пока ENABLE_PAID_X=1. Нужен X_BEARER_TOKEN. Приложение не контролирует тарификацию провайдера. Бесплатного полного потока X здесь нет.

**Crawler:** до трёх страниц сайта/GitHub/docs, без выполнения JavaScript. Частные адреса и перенаправления к ним блокируются; соединение фиксируется на проверенном IP. Некоторые сайты не отдают данные crawler.

**JSON:** кнопка импорта или data/inbox/*.json, до 1000 постов / 30 проектов / 2 MB. В inbox сначала пиши .tmp и затем переименовывай в .json. Обработанные файлы перемещаются в data/processed.

```json
{"posts":[{"id":"unique-id","author":"researcher","text":"Public project release","project_url":"https://example.com/project","project_name":"Example","followers":240,"created_at":"2026-10-05T12:00:00Z"}]}
```

project_name и followers необязательны. Дедупликация по источнику и ID, агрегация двухчасового окна. Рост без предыдущего часа неизвестен. Разные домены одного проекта автоматически не объединяются. Ручные черновики в Launch studio сохраняются отдельно и не поступают в автоматическую очередь.

## Проверки и границы готовности

```sh
python3 -m unittest discover -s tests -v
npm test
node --check static/app.js
npm audit
```

27 тестов: поиск, SSRF-защита, импорт, квоты, перезапуск, dry/live, исключение demo, инструкции транзакций, пауза, сохранение перед отправкой и запрет повторной отправки после таймаута. npm audit: 0 известных уязвимостей на момент проверки.

Проверен настоящий ответ PumpPortal: unsigned zero-buy create, 3 инструкции, таблицы адресов и совместимый вариант create_v2. Публичный fixture без ключей - tests/provider-fixture.json. Повторить: `node launch/check-provider.mjs`; он ничего не подписывает и не отправляет в блокчейн.

**Реальное создание токена и загрузка Pinata ещё не проверены:** не подключены Pinata JWT и средства. Успешный unsigned probe не заменяет on-chain end-to-end проверку. При изменении формата провайдера валидатор останавливает запуск. Визуальная проверка через инструмент браузера недоступна; HTTP и код интерфейса проверяются отдельно.

Сервер слушает только localhost. Публичное размещение потребует аутентификации и отдельного сервера приложений.
