How to feed data

Import JSON with the button at the top or drop a file into data/inbox/. Autopilot checks the folder every 5 minutes while the server runs.

Connection keys are set locally through environment variables. They are never shown in the dashboard.

What the checks mean

In this version DOTS is four independent rule-based checks, not four LLMs. A shortlist means the minimum evidence is present. It does not confirm safety, team authenticity or investment value.
